## API

Inputs used by the examples on this page:

| Input              | Type      | Default | Description                                                                                                                                                                                   |
| ------------------ | --------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [fixedPlaceholder] | `boolean` | `true`  | Keep the placeholder rendered when an item is selected. Visibility is theme-dependent: the default and Ant Design themes hide it once a value is set, the Material theme floats it as a label |
| placeholder        | `string`  | `-`     | Placeholder text.                                                                                                                                                                             |

See the `NgSelectComponent` API reference for the complete list of inputs and outputs.
