Each major version of ng-select targets a specific range of Angular versions.

:::caution
Do not use versions 15.2.0, 16.0.0, 17.0.0, 18.0.0, 19.0.0, 20.0.0 as they contain unresolved issues.
:::

| Angular             |       ng-select       |
| ------------------- | :-------------------: |
| >=22.0.0 &lt;23.0.0 |        v23.x.x        |
| >=21.0.0 &lt;22.0.0 |        v21.x.x        |
| >=20.0.0 &lt;21.0.0 | &lt;=15.1.3, >=20.0.1 |
| >=19.0.0 &lt;20.0.0 |         v14.x         |
| >=18.0.0 &lt;19.0.0 |         v13.x         |
| >=17.0.0 &lt;18.0.0 |         v12.x         |
| >=16.0.0 &lt;17.0.0 |         v11.x         |
| >=15.0.0 &lt;16.0.0 |         v10.x         |
| >=14.0.0 &lt;15.0.0 |         v9.x          |
| >=13.0.0 &lt;14.0.0 |         v8.x          |
| >=12.0.0 &lt;13.0.0 |         v7.x          |
| >=11.0.0 &lt;12.0.0 |         v6.x          |
| >=10.0.0 &lt;11.0.0 |         v5.x          |
| >=9.0.0 &lt;10.0.0  |         v4.x          |
| >=8.0.0 &lt;9.0.0   |         v3.x          |
| >=6.0.0 &lt;8.0.0   |         v2.x          |
| v5.x.x              |         v1.x          |

See the [CHANGELOG](https://github.com/ng-select/ng-select/blob/master/CHANGELOG.md) for release notes.
