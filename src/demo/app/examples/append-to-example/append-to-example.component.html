The dropdown panel renders in an Angular CDK overlay and paints in the browser's top layer wherever the native Popover API is supported, so clipping and stacking are handled without configuration. Use appendTo only when the panel must live inside a specific element in the DOM — e.g. to inherit ancestor-scoped styles or satisfy focus containment.
