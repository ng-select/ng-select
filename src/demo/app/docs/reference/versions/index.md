Each major version of ng-select targets a specific range of Angular versions.

> **Warning**
> Do not use versions 15.2.0, 16.0.0, 17.0.0, 18.0.0, 19.0.0, 20.0.0 as they contain unresolved issues.

| Angular          |     ng-select      |
| ---------------- | :----------------: |
| >=22.0.0 <23.0.0 |      v23.x.x       |
| >=21.0.0 <22.0.0 |      v21.x.x       |
| >=20.0.0 <21.0.0 | <=15.1.3, >=20.0.1 |
| >=19.0.0 <20.0.0 |       v14.x        |
| >=18.0.0 <19.0.0 |       v13.x        |
| >=17.0.0 <18.0.0 |       v12.x        |
| >=16.0.0 <17.0.0 |       v11.x        |
| >=15.0.0 <16.0.0 |       v10.x        |
| >=14.0.0 <15.0.0 |        v9.x        |
| >=13.0.0 <14.0.0 |        v8.x        |
| >=12.0.0 <13.0.0 |        v7.x        |
| >=11.0.0 <12.0.0 |        v6.x        |
| >=10.0.0 <11.0.0 |        v5.x        |
| >=9.0.0 <10.0.0  |        v4.x        |
