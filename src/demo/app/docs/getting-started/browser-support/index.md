ng-select supports all browsers supported by Angular. For the current list, see the [Angular browser support guide](https://angular.dev/reference/versions#browser-support). This includes the following specific versions:

| Browser | Supported versions                        |
| ------- | ----------------------------------------- |
| Chrome  | 2 most recent versions                    |
| Firefox | latest and extended support release (ESR) |
| Edge    | 2 most recent major versions              |
| Safari  | 2 most recent major versions              |
| iOS     | 2 most recent major versions              |
| Android | 2 most recent major versions              |
